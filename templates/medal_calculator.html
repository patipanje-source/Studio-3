How this project calculation works

The official best valid jump is the raw result. The calculator applies the 2025/2026 World Para Athletics Raza points parameters for the athlete’s T61–T64 class and recorded gender. Ranks sort by unrounded points; displayed and saved points are rounded to a whole number to fit the project’s existing results table. A tie is compared using each athlete’s next-best valid attempt points. If still tied, they share rank. The top three ranks receive the project’s gold, silver, or bronze award. This open event and its medal policy are project choices, not a claim that all official competitions combine these classes or award medals this way.

Attempts are saved in centimetres (the official recording precision) in the existing result tables; the page displays them as metres. A valid mark rounds down to the nearest centimetre, as the WPA long-jump rule specifies.
